# 🔮 scry.quest 🔮

*Roll for initative! 🎲⚔️*

Welcome, brave adventurer, to **scry.quest** - an AI-powered dungeon master that scrys the depths of Dungeons and Dungeons & Dragons 5E ™️ lore!

📖 This grimoire aids adventurers in their most perilous sessions, wielding the complete System Reference Document [SRD CC v5.2.1](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf) as its compendium. 📚✨
